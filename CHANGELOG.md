# Changelog

All notable changes to Devbox Cloud Tools will be documented here.

## [0.2.0] - 2024-01-03

### Added
- Renamed to "Devbox Cloud Tools"
- Remote runner support for iOS simulators and Android emulators
- Magic link setup for zero-config runner installation
- Runner dashboard with real-time status
- Remote screenshot capture
- Remote Maestro flow execution
- Coordinator service for runner management

## [0.1.0] - 2024-01-02

### Added
- Initial release as CloudDev Helper
- Android emulator integration via noVNC
- Flutter and Expo app launching
- Maestro test automation support
- Local screenshot capture
